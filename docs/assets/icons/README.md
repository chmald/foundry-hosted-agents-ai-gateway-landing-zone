## Sources

| Icon set | Source | Used for |
|---|---|---|
| **Azure Architecture Icons (V24)** | [Azure architecture icons](https://learn.microsoft.com/en-us/azure/architecture/icons/) | Azure services (Foundry, API Management, AI Gateway, Container Apps, Key Vault, Monitor, networking, and so on). The July 2026 icon update added the AI Gateway and Foundry icons. |
| **Microsoft Entra architecture icons** | [Microsoft Entra architecture icons](https://learn.microsoft.com/en-us/entra/architecture/architecture-icons) | Identity products (Entra ID, Workload ID, ID Governance, ID Protection, app registrations, enterprise applications, roles). |

## Terms summary

> [!IMPORTANT]
> This is a summary, not the license. Read the terms on the two Learn pages above before reuse.

Microsoft permits the use of these icons in architectural diagrams, training materials, or documentation. You can copy, distribute, and display the icons only for the permitted use unless granted explicit permission by Microsoft. Microsoft reserves all other rights.

| Do | Don't |
|---|---|
| Use the icons to illustrate how products work together. | Crop, flip, or rotate the icons. |
| Include the product name near the icon. | Distort the icons or change their shape. |
| Use the icons as they appear in Azure. | Use Microsoft product icons to represent your own product or service. |
| Keep them in documentation, diagrams, and training material. | Use the Entra icons in marketing communications. |

> [!NOTE]
> The documentation sizes icons with the `width` attribute only, so the aspect ratio is preserved.

## Using an icon in a doc

```html
<img src="./assets/icons/api-management.svg" width="20" alt="API Management"> API Management
```

Always show the product name next to the icon, size with `width` only, and use `alt=""` when the name is already adjacent in a table cell.
